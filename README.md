# DonCode: Стажёр

Браузерная 3D-игра для подростков о профессии программиста. Игрок — стажёр в IT-компании:
ходит по офису, общается с коллегами и выполняет их задания в виде интерактивных мини-игр.

**Стек:** JavaScript (ES-модули), [Three.js](https://threejs.org/) для 3D, Vite для сборки. Бекенда нет,
прогресс сохраняется в `localStorage`.

## Запуск

```bash
npm install
npm run dev      # dev-сервер на http://localhost:5173 (доступен и по локальной сети, удобно для теста на телефоне)
npm run build    # статическая сборка в dist/ — можно выложить на GitHub Pages / Netlify / любой хостинг
npm run preview  # просмотр собранной версии
```

## Управление

| Платформа | Ходить | Камера | Действие |
|-----------|--------|--------|----------|
| ПК | `WASD` / стрелки, `Shift` — бег | зажать мышь и вести | `E` / `Enter` |
| Телефон / планшет | стик слева | провести пальцем по экрану | жёлтая кнопка справа |

| NPC | Роль | Где | Мини-игра |
|-----|------|-----|-----------|
| Аня | UI/UX-дизайнер | open-space, у доски | **Покрась кнопку**: подобрать CSS-цвет и скругление по макету |
| Максим | Тимлид | open-space | **Найди баг**: по упавшему тесту найти строку с ошибкой и выбрать исправление |
| Серёга | DevOps-инженер | серверная | **Почини пайплайн**: расставить шаги CI/CD по порядку |
| Ольга Петровна | Технический директор | кабинет директора | **Приветствие**: собрать функцию `greet(name)` из блоков |

Квесты берутся в любом порядке. После каждого показывается карточка «Что ты узнал», а после всех четырёх — финал.
Таймеров и штрафов нет: при ошибке игрок получает дружелюбную подсказку.

## Структура

```
src/
  main.js            стартовый экран (никнейм / продолжить)
  game.js            сцена, игровой цикл, диалоги, запуск мини-игр
  state.js           состояние и сохранение в localStorage
  input.js           клавиатура, мышь, сенсорный стик
  world/
    office.js        офис: помещения, мебель, коллайдеры, точки (spots)
    characters.js    сборка low-poly персонажей из описания стиля
    player.js        движение, столкновения, камера за спиной
    npc.js           NPC со значками «!» / «…» / «✓» и маркеры квестов на полу
  quests/
    npcs.js          персонажи: внешность, роль, место
    quests.js        квесты: диалоги, мини-игра, точка выполнения, обучающий текст
  minigames/         мини-игры в модальных окнах + реестр index.js
  ui/                модальные окна, HUD, DOM-хелпер
```

## Как добавить новый квест

1. **Мини-игра.** Создайте `src/minigames/myGame.js`:
   ```js
   export default {
     id: 'my-game',
     title: 'Название',
     mount(root, { playerName, complete }) {
       // нарисуйте интерфейс внутри root; вызовите complete(), когда задание выполнено
     },
   };
   ```
   и добавьте её в список в `src/minigames/index.js`.
2. **NPC** (если нужен новый): добавьте запись в `src/quests/npcs.js` (стиль — цвета, причёска, аксессуары)
   и точку `spots.<имя>` в `src/world/office.js`.
3. **Квест**: добавьте объект в `src/quests/quests.js` с полями `npc`, `minigame`, `spot` (где стоит маркер),
   диалогами `intro / active / done` и карточкой `lesson`. В текстах `{name}` заменяется на никнейм игрока.

В dev-режиме в консоли браузера доступен `window.__game` (телепорт, открытие диалогов и мини-игр) для отладки.
